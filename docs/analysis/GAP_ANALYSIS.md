# Expansion gap analysis

The current code has a pond `farmId`, but no complete legal-entity/farm membership hierarchy. Water contracts contain temperature and pH only. Crop, livestock, dairy, poultry and specialist enterprise records, offline synchronization, shared material movements, commercial traceability and ERPNext integration require additions. Indian statutory acceptance additionally requires real legal-entity/state configuration and accountant-approved cases.

The implementation must distinguish a configured integration from a successful provider posting and a synthetic verification from production acceptance.
